# Ours 强制技能（每会话生效）

本工作区每一次 Agent 对话均必须遵守以下技能（位于 `.kiro/skills/`）：

1. **必须**按 `wechat-miniprogram-dev` 处理所有与代码、配置、提审、调试相关工作（含 `miniprogram/`、`project.config.json` 等）。
2. **必须**按 `online-search`：凡涉及微信官方规则、接口/基础库版本、依赖与 CVE、错误码与平台文案等可能随时间变化的信息，**先检索或拉取权威来源再下结论**，不得仅凭训练数据断言。
3. **必须**按 `karpathy-guidelines` 编写、审查或重构代码：先澄清假设、保持简单、只做与需求直接相关的改动、给出可验证的成功标准。
4. 涉及页面视觉、组件样式、品牌调性、动效与布局时，**必须**先按 `frontend-design` 做设计思考再实现（在 WXML/WXSS 约束下落地）。

若用户问题与小程序或联网无关（例如纯闲聊），仍需遵守第 2 条「平台与依赖类事实需核实」原则；其余可正常简短回答。

## 项目要点（OursWXAPP）

- 产品定位见 `docs/产品功能说明.md`：两个人的私密朋友圈，主打**动态时间轴**。
- v0.1 范围：**绑定 / 动态（发布+时间轴+详情）/ 首页（天数+轻打卡+最近预览）/ 我们（资料+开始日期+隐私）**。明确**不做**：纪念日、足迹地图、吐槽墙、小纸条、动态评论/爱心、互动 Tab、标签筛选、每日一问。
- Tab 结构（v0.1）：**首页 · 动态 · 我们**，共 3 Tab。
- 视觉系统：**Cinema Ours**（电影/胶片/场记/宽银幕/字幕；色板见 `docs/产品功能说明.md` §10.1）。
- 导航栏标题：`Ours`。
- 数据：使用微信云开发；当前 `appid: touristappid` 阶段以本地 `wx.setStorage` 兜底，封装在 `miniprogram/services/store.ts` 后面，后续替换为 `wx.cloud` 调用零改动调用方。
