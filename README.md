# Ours

**两个人的照片日记，把一起的日子慢慢记下来。**

**简体中文** | [English](./README.en.md)

Ours 是一个面向情侣的微信小程序，用一个双人空间保存照片、文字、视频、语音和一起走过的地方。从今天的一顿饭，到值得纪念的一次旅行，都可以成为时间轴上的一段回忆。

本仓库包含微信小程序、云函数和独立网页管理台。小程序当前界面为中文。

[功能亮点](#功能亮点) · [快速开始](#快速开始) · [开发命令](#开发命令) · [常见问题](#常见问题) · [更多文档](#更多文档)

## 功能亮点

| 功能 | 说明 |
| --- | --- |
| 双人专属空间 | 使用管理员生成的一次性授权码激活空间，再通过专属邀请链接连接另一位成员；每个空间最多两人。 |
| 多媒体回忆 | 支持文字、照片、GIF、实况照片、视频和语音，可添加标签、地点和回忆日期，也能补录过去的日常。 |
| 回忆时间轴 | 按日期浏览、分页加载、关键词搜索和标签筛选；支持「那年今日」和详情页上一条 / 下一条导航。 |
| 足迹、合辑与回顾 | 在地图上查看记录过的地点，按标签或地点浏览合辑，按年份和月份查看统计与照片回顾。 |
| 双人互动 | 在回忆详情中发表评论、点亮爱心；作者可以编辑回忆的文字、日期、标签和地点。 |
| 相伴与纪念日 | 展示在一起的天数，管理纪念日，并在首页查看下一个纪念日倒计时。 |
| 个性化设置 | 修改自己的头像、昵称和相伴开始日期；提供淡紫、暖杏、薄荷、天蓝四种色系。 |
| 回忆备份 | 将记录与媒体原文件导出为分卷 ZIP，包含记录、媒体映射和导出状态清单。 |
| 独立网页管理台 | 管理员可生成授权码、查看空间与成员、调整额度、浏览记录和媒体，以及删除空间。 |

当前小程序使用 **首页 / 回忆 / 我们** 三个 Tab。发布草稿会在本机保存；发布重试、点赞重试和媒体清理也有对应的可靠性处理。

## 技术栈

| 部分 | 技术 |
| --- | --- |
| 微信小程序 | 原生小程序、TypeScript、WXML、WXSS |
| 业务后端 | 微信云开发、Node.js、`wx-server-sdk`、云数据库与云存储 |
| 网页管理台 | React 18、TypeScript、Vite 5、CloudBase Web SDK |
| 管理接口 | Node.js、`@cloudbase/node-sdk`、管理员白名单校验 |
| 备份导出 | `archiver`，生成包含 JSON 记录与媒体原文件的 ZIP |

## 快速开始

### 1. 准备环境并安装依赖

- 安装 Node.js 20 或以上版本及 npm，用于本地开发。
- 安装微信开发者工具，准备已开通云开发的小程序 AppID。
- 创建自己的微信云开发 / CloudBase 环境，启用云数据库、云函数和云存储。

```bash
git clone https://github.com/Haoog/Ours.git
cd Ours
npm ci
```

根目录依赖用于 TypeScript 与本地校验。管理台和两个云函数有各自独立的依赖。

### 2. 配置 AppID 与云环境

在微信开发者工具中导入**仓库根目录**。项目已配置 `miniprogram/` 为小程序目录、`cloudfunctions/` 为云函数目录，并启用了 TypeScript 编译插件。

使用自己的配置替换仓库中的现有值：

| 文件 | 配置项 |
| --- | --- |
| [`project.config.json`](./project.config.json) | 将 `appid` 改为自己的小程序 AppID。 |
| [`miniprogram/config/env.ts`](./miniprogram/config/env.ts) | 将 `CLOUD_ENV_ID` 改为自己的云环境 ID。 |
| `admin-web/.env` | 在第 4 步创建，并将 `VITE_CLOUD_ENV_ID` 改为同一个云环境 ID。 |

例如，小程序环境配置为：

```ts
export const CLOUD_ENV_ID = 'your-cloud-env-id'
```

### 3. 初始化数据库并部署云函数

在云开发控制台创建以下 **11 个集合**，数据库权限建议配置为仅云函数可读写：

| 用途 | 集合 |
| --- | --- |
| 空间与回忆 | `couples`、`moments` |
| 纪念日与回忆互动 | `anniversaries`、`moment_comments`、`moment_likes` |
| 历史功能数据与兼容接口 | `checkins`、`rants`、`notes` |
| 授权、邀请与管理员 | `access_codes`、`space_invites`、`admins` |

按照 [云开发部署说明](./cloud/README.md) 建立对应索引；索引是时间轴、筛选和空间查询正常运行的重要配置。

在微信开发者工具中，分别右键以下目录，选择 **上传并部署：云端安装依赖**：

1. `cloudfunctions/ours`
2. `cloudfunctions/admin-api`

云函数运行时使用 Node.js 18 或以上。`ours` 建议配置 **512 MB 内存、120 秒超时**，以支持媒体备份分卷；云端需安装包括 `archiver` 在内的依赖。`admin-api` 建议至少 15 秒超时，以便汇总历史媒体用量。

`ours/config.json` 已声明 `security.msgSecCheck` 权限。请先部署两个云函数，再运行或发布小程序与管理台。

### 4. 启动网页管理台并初始化管理员

```bash
cd admin-web
cp .env.example .env
```

编辑 `.env`，填写第 2 步使用的云环境 ID：

```dotenv
VITE_CLOUD_ENV_ID=your-cloud-env-id
```

然后启动管理台：

```bash
npm ci
npm run dev
```

打开终端显示的本地地址，并完成首次授权：

1. 在 CloudBase 控制台开启账号密码登录，并创建管理台账号。
2. 使用该账号登录网页；尚未授权时，页面会显示当前账号的 `uid`。
3. 在 `admins` 集合新增一条文档：

   ```json
   {
     "uid": "uid-shown-on-the-login-page",
     "role": "superadmin",
     "status": "active"
   }
   ```

4. 刷新网页，进入「概览 / 邀请码 / 双人空间」。

管理台部署到 CloudBase 静态网站托管的步骤见 [管理台说明](./admin-web/README.md)。`VITE_CLOUD_ENV_ID` 是构建时变量，修改后需重启开发服务或重新构建。

### 5. 激活空间并邀请另一位成员

1. 在网页管理台生成一次性授权码，设置动态数量、媒体数量、单条媒体数、存储额度及相关到期时间。
2. 在微信开发者工具中编译小程序，输入授权码、头像、昵称和相伴开始日期，激活空间。
3. 进入「我们」，生成第二位成员的专属邀请卡片并分享给对方。
4. 对方通过带邀请 token 的卡片加入同一空间；邀请默认 7 天有效，每个空间最多两人。
5. 点击「+」发布第一条回忆，在「回忆」中查看时间轴、足迹、合辑与回顾。

授权码用于首次激活空间，成员邀请用于连接第二位成员，两者用途不同。直接搜索打开小程序会进入激活流程；加入已有空间需要使用邀请卡片。

## 开发命令

以下命令均在**仓库根目录**执行：

| 命令 | 用途 |
| --- | --- |
| `npm ci` | 安装根目录依赖。 |
| `npm run typecheck` | 检查小程序 TypeScript 类型。 |
| `npm run verify:core` | 使用本地模拟数据库与微信 API 校验核心流程，不连接线上数据。 |
| `npm --prefix admin-web ci` | 安装管理台依赖。 |
| `npm run admin:dev` | 启动管理台开发服务；需先配置 `admin-web/.env`。 |
| `npm run admin:build` | 类型检查并构建管理台，输出到 `admin-web/dist/`。 |

`verify:core` 覆盖发布去重、媒体引用保护、事务回滚与删除补偿、作者编辑权限、点赞重试、草稿恢复和 ZIP 原文件导出。小程序的编译、预览和上传通过微信开发者工具完成。

## 权限与使用边界

- 普通用户的数据访问由云函数校验微信身份及空间成员关系；授权管理员可以通过管理台查看空间内的记录和媒体。
- 动态数、媒体数、单条媒体数和存储额度由云函数校验；实际额度取决于管理台配置。
- 备份入口为「我们 → 备份回忆」。每卷最多包含 10 个媒体文件，并附带 `records.json`、`media-manifest.json` 和 `backup-status.json`；未能导出的文件会列在状态清单中。
- 纪念日支持记录与倒计时，当前页面未接入订阅消息提醒。
- 实况照片、定位、录音和文件分享等微信能力需要在真机环境验证。

## 常见问题

| 问题 | 排查方式 |
| --- | --- |
| 启动时提示「暂时连不上」 | 确认小程序云环境 ID、开发者工具所选环境一致，两个云函数已部署，并已创建所需集合。 |
| 没有邀请码，无法进入首页 | 先初始化管理台管理员，再生成一次性授权码；新用户需要先激活空间。 |
| 第二位成员无法加入 | 通过创建者生成的专属邀请卡片进入，确认邀请未过期且空间尚未满员。 |
| 管理台显示「当前账号尚未授权」 | 检查 `admins` 文档的 `uid` 是否与登录页一致，且 `status` 为 `active`。 |
| 修改管理台环境后仍访问旧环境 | 检查 `.env` 的 `VITE_CLOUD_ENV_ID`，重启开发服务；已部署站点需重新构建并上传。 |
| 备份失败或有文件缺失 | 确认已部署包含 `archiver` 的新版 `ours`，检查云函数超时与内存配置，并查看包内 `backup-status.json`。 |
