## 1. 产品定位

**一句话：** **两个人的私密朋友圈**——像微信朋友圈一样记图文、地点与旅途；其它能力都是让这条时间轴更好用、更有仪式感的插件。

| 维度 | 说明 |
|------|------|
| 使用者 | 仅绑定的一对情侣（两人） |
| **主打** | **动态（朋友圈式时间轴）** — 发图文、看时间轴、点详情 |
| 辅助 | 在一起天数、轻量每日打卡 |
| 插件（分版上线） | 纪念日、足迹地图、动态评论、吐槽墙、小纸条、每日一问、清单等 |
| 技术 | 微信小程序 + **微信云开发** |
| 品牌 | `OursWXAPP` · 暖米色、安静日记感，避免廉价粉红模板风 |

**明确不做：** 公开社区、陌生人、排行榜裂变、现金打卡挑战、复杂养宠/小镇、自动后台定位、两人以外的多人空间。

### 1.1 功能层级（已定）

| 层级 | 功能 | 产品角色 |
|------|------|----------|
| **主菜** | 发动态 + 时间轴 + 详情大图 | 每天打开的主场景；数据与时间越久越有价值 |
| **配菜** | 在一起天数、纪念日倒计时、每日打卡 | 首页仪式感；不抢时间轴篇幅 |
| **加料** | 吐槽墙、小纸条、每日一问、罚单、清单 | 需要时去「互动」；**优先在动态下评论**吐槽某条记录 |

> **定调：** Ours = 两个人的私密朋友圈；不做成功能堆砌的「恋爱工具箱」。

---

## 2. 设计原则

1. **朋友圈记录为主轴** — 所有能力优先问：能否增强时间轴？不能的放插件区。  
2. **完整愿景、分版交付** — 功能清单写全；**v0.1 只做透动态 + 天数 + 轻打卡**。  
3. **私密优先** — 全部为双人可见；地点仅「发内容时主动选点」。  
4. **记录与互动分层** — 正式记录走动态；碎话/互怼走评论或吐槽墙，不另造第二套朋友圈。  
5. **云端同步** — 云数据库 + 云存储，两人换机数据一致。

## 4. 功能模块总览

> 下列模块均保留在愿景内；**版本归属见 §5**。未标版本的默认晚于 v0.1。

### 4.1 动态（朋友圈式记录）— 【主打 · 核心 · 已实现】

| 元素 | 说明（**当前代码**） |
|------|----------------------|
| 文字 | 不设字数上限 |
| 照片 | **数量不限**；单次相册最多选 20 张，可多次添加；原图上传（保留 GIF） |
| GIF | `<image>` 自动播放；选图须 `original`，勿压缩 |
| 长视频 | 每条动态 **1 个**；相册/拍摄，最长 60 秒 |
| iPhone 实况 | 识别「短视频（≤约 4.5s）+ 缩略图」；封面+配对视频，轻触播放；专用 **Live** 入口 |
| 语音 | 每条 **1 条**；录音最长 60 秒，`mp3` 上传云存储 |
| 混发 | **同一条**内可组合：多图 + 实况 + 长视频 + 语音 + 文案 |
| 地点 | 可选 `chooseLocation` |
| 作者 | 按 openid 区分 **我 / 她**（`authorRole` A/B） |
| 标签 | `旅行` `日常` … — **v0.2，当前未做** |
| 评论 / 爱心 | **v0.2，当前未做** |

**发布页（`pages/compose`）入口：** 相册 · Live（实况）· 视频 · 语音。

**展示：** 回忆时间轴可叠放展示视频、实况、语音条、多图/单图/纯文字；详情页大图预览、语音播放、实况组件 `live-photo`。

```
文案 + [相册/实况/视频/语音] + [地点] → 上传云存储 → 写入 moments
```

### 4.2 在一起天数 — 【配菜 · v0.1】

- 设定「开始日期」，首页 **第 N 天**  
- 可选：100 天 / 周年等里程碑弱提醒（不弹窗轰炸）  
- 开始日期**可以修改**（在「我们」里改，建议二次确认）  

### 4.3 纪念日 — 【配菜 · v0.2】

- 多条目：标题、日期、**每年重复**（生日、周年）  
- 首页：**下个纪念日还有 X 天**  
- 列表页：全部纪念日 + 已过 / 即将到来  
- **订阅消息**提醒（前 1 天，需授权）  
- 可与「动态」联动：到日自动提示「写一条纪念日动态」  

### 4.4 每日打卡 — 【配菜 · v0.1 轻量】

参考恋爱记/Connected 的「连接感」，做**轻量版**（无现金、无第二套信息流）：

| 项 | 说明 |
|----|------|
| 打卡动作 | 每日一次，可选附一句（早安/晚安/想你/自定义） |
| 双人完成 | 显示今日「你 / TA 是否已打卡」 |
| 连续天数 | **一起连续** streak：**两人都打卡**的当天才算第 1 天，只一人打不计入（见 §7.1） |
| 心情 | 四档：`挺好` / `平静` / `低落` / `想说`（存库为 `happy`/`soft`/`low`/`rant`） |
| 入口 | 首页**双人签到卡** + 底部弹层；**不做**独立 Tab / 历史日历页（**待做**） |
| 与时间轴关系 | v0.2 可选：双人打卡成功后插入一条**系统样式**时间轴卡片（「今天两人都打卡了」） |

### 4.5 足迹 / 旅游打卡 — 【插件 · 地点先随动态 · 地图 v0.2】

| 阶段 | 能力 |
|------|------|
| v0.1 | 动态上挂地点，列表展示 📍 |
| v0.2 | **足迹地图**：marker 聚合，点进动态；**城市列表**（去重统计） |

### 4.6 互动：吐槽、树洞、小纸条 — 【加料 · v0.2 起】

> 满足「互相吐槽」等情绪表达，**不做成公开评论区**，保持双人私密。  
> **优先路径：** 针对某次旅行/纪念日 → **在该条动态下评论**；吐槽墙留给没图、纯情绪的碎话。

| 模块 | 形态 | 说明 |
|------|------|------|
| **动态下评论** | 挂在某条动态下 | **首选**互怼/吐槽场景（v0.2） |
| **吐槽墙** | 「互动」Tab | 文本，可 1～3 图；偏放飞（v0.2） |
| **小纸条** | 轻量私信 | 一条一条，像便签；阅后即焚可选（v0.3） |
| **恋爱罚单**（趣味） | 模板 + 自定义 | 参考恋爱记「开罚单」：如「迟到券」「请喝奶茶券」，纯娱乐、无支付 |
| **每日一问** | 系统/自定义问题 | 双方**先答后可见**对方答案；历史问答列表 |
| **想你 / 戳一下** | 一键通知 | 对方打开小程序看到「TA 想你了」；用订阅消息或首页未读角标（需授权） |

**与动态的区别：**

- **动态** = 正式记录、相册感、可带多图与地点  
- **吐槽墙 / 小纸条** = 即时、碎、情绪向，列表更紧凑  

### 4.7 心情日记（可选模块）

- 除打卡 emoji 外，可写**仅自己可见 / 双方可见**的短日记（待拍板默认双方可见）  
- 与动态合并实现：标签 `心情` + 较短正文，减少重复建设  

### 4.8 愿望 / 100 件小事清单（v0.3）

- 一起建清单项 → 完成打勾 → 可关联一条动态作证明  
- 参考恋爱记「100 件小事」  

### 4.9 双人绑定 — 【已定：邀请码 + 专属邀请链接 · 已实现】

空间授权与双人绑定分成两步：管理台生成一次性邀请码，客户兑换后创建空间；空间创建者再生成只能使用一次的第二位成员邀请链接。

| 角色 | 流程 |
|------|------|
| 管理员 | 网页管理台生成一次性邀请码，可设置动态/媒体/存储/到期额度 |
| **你（memberA）** | 首次打开 → `pages/setup` 填邀请码、开始日期与昵称 → 兑换并进入首页 |
| **她（memberB）** | 创建者在「我们」页生成专属邀请链接 → 分享卡片 → 打开后自动加入 |

```
管理员：网页生成 access code → 发给客户
你：setup 兑换 access code → 创建空间 → bind 生成 space invite token
她：点分享卡片 → bootstrap / joinPartnerInvite → 双方可见同一 moments / checkins
```

- 邀请码只能兑换一次；空间最多两名成员；第二位成员邀请链接默认 7 天有效。  

### 4.10 暂不纳入

- 完整 IM（语音视频聊天）— 用树洞+小纸条+评论代替

## 6. 信息架构

### 6.1 Tab 结构

**v0.2（4 Tab — 已实现）：**

```
[ 首页 ]  第 N 天 · 签到 · 下个纪念日 · 最近 3 条 · 「+」
[ 回忆 ]  时间轴/地图/合辑/回顾 · 那年今日 · 搜索 · 标签筛选 · 列表互动数 · 详情翻页 · 「+」
[ 互动 ]  吐槽墙 · 小纸条
[ 我们 ]  纪念日 · 足迹地图 · 昵称 · 隐私
```

**非 Tab 页面：** `setup`（首次创建）、`compose`（记一条）、`moment-detail`、`bind`（邀请她）。

**v0.2 起（4 Tab）：**

```
[ 首页 ]  天数 · 轻打卡 · 纪念日倒计时 · 最近动态
[ 动态 ]  时间线 + 发布 + 评论/爱心
[ 互动 ]  吐槽墙 · 小纸条
[ 我们 ]  纪念日管理 · 足迹地图 ·（v0.3 清单）
```

> **首页 vs 回忆（已定：双 Tab）**  
> - **首页** = 仪表盘：在一起天数、打卡状态、最近 3 条预览、「全部回忆 →」、悬浮「+」。  
> - **回忆** = 完整时间轴主战场；**上拉加载更多**，每页 20 条；内嵌 **地图/合辑/月度回顾** 子视图。  
> 不合并为单 Tab，避免首页过长、也避免没有「抬头」仪式感。

**回忆 Tab 子能力（v2.1）：**

| 能力 | 说明 |
|------|------|
| 片段馆 | 胶片卷轴式卡片（齿孔+SCENE 序号+水印）；影院/Bento/胶片条/诗卡 四种版式；`previewImages` 批量换链 |
| 那年今日 | 横滑条，同月同日历史动态 |
| 地图 | Tab 内嵌地图（与「我们」→ 足迹地图数据同源 `listMapPlaces`） |
| 合辑 | 按标签/地点聚合，点标签回时间轴筛选 |
| 回顾 | 选月份看条数、双方贡献、地点数、最常标签 |

## 7. 规则与权限

| 问题 | 已定 |
|------|------|
| 删动态 | 两人都能删 |
| 改动态 | v0.3 再支持；此前删重发 |

| 视频 / 语音 / 实况 | 每条动态：长视频 ≤1、语音 ≤1、实况若干（识别添加） |
| 地点 | 可选 |
| 打卡 | 每日每用户 1 次；不允许补卡；**仅自己可签**（不能代 TA 签） |

| 改昵称 | 我们页修改 **当前身份** 昵称 |

### 7.1 连续打卡 streak（已定）

展示一个数字：**「我们一起连续打卡 N 天」**。

| 规则 | 说明 |
|------|------|
| **两人都打才算**（采用） | 同一天**两人都打卡**才 `advanceStreak`；打卡时会检查**昨日**是否双人完成，若昨日仅一人打则 **streak 清零**（云函数 `reconcileStreak`） |
| ~~各算各的~~（未采用） | 你连续 30 天、TA 连续 5 天，各显示各的；更像个人习惯，不像「一起」 |

**举例（两人都打才算）：**

- 周一：两人都打 → 连续 1 天  
- 周二：只有你打 → 连续**中断**（周二不算）  
- 周三：两人都打 → 连续重新从 1 天开始  

若你希望改成「各算各的」，开发前说一声即可。

## 9. 关键流程

### 9.0 首次进入与绑定

```
启动 → wx.cloud.init → 云函数 bootstrap
  → 无空间：跳转 setup → redeemAccessCode → 首页
  → 带 inviteToken：joinPartnerInvite → 首页
  → 已绑定：进入 Tab 首页
分享：bind 带 inviteToken → bootstrap 传 token → joinPartnerInvite
```

### 9.1 每日打卡

```
打开首页 → 见「今日你/TA 未打卡」→ 点打卡 → 选心情 + 写一句 → 提交
  → 若两人均已打卡 → streak +1，首页展示连续天数
```

### 9.1b 发布动态（当前）

```
回忆/首页点 + → compose
  → 选相册 / Live / 视频 / 录音
  → 可选地点 → 上传云存储 → 云函数 addMoment
  → 回到回忆 Tab 刷新时间轴
```

### 9.2 发吐槽

```
[互动] → 吐槽墙 → 写短句（可配图）→ 发布 → 对方在互动 Tab 看到未读
```

### 9.3 纪念日

```
[我们] → 纪念日 → 添加 → 首页显示最近一个倒计时
  → 到期前 1 天订阅消息（已授权）
```

### 9.4 每日一问（v0.3）

```
今日问题 → 自己先答 → 保存后显示「等 TA 回答」→ 双方都答后揭晓对方答案
```

| 10 | **可拖动浮窗小猫** / **我们** → 我们的小猫 | 拖动浮窗调整位置，点浮窗展开喂食/抚摸；演示数据含「小紫」 |

## 16. 从零自测（没有数据时怎么做）

> 小程序**不会**自带示例数据；空库第一次打开会进 **创建空间** 页，这是正常流程。

### 16.1 环境准备（一次性）

1. 微信开发者工具打开本项目，确认 `miniprogram/config/env.ts` 中云环境 ID 与控制台一致。  
2. 右键 `cloudfunctions/ours` → **上传并部署：云端安装依赖**（含 `seedDemoData` 等新 action）。  
3. 云开发控制台创建集合：`couples`、`moments`、`checkins`、`anniversaries`、`rants`、`notes`、`moment_comments`、`moment_likes`（权限建议仅云函数可写）。  

若启动弹窗「暂时连不上」→ 云函数未部署或集合未建，**不是**缺数据问题。

### 16.2 第一次使用（真人流程）

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 编译运行（须为 **开发版**，详情里可看到 `envVersion: develop`） | 无空间 → `setup` 创建页 |
| 2 | 填昵称、开始日期 → **创建空间** | 进入首页 Tab，天数显示，最近记录为空 |
| 3 | 右下角 **+** → 写一条纯文字 → 保存 | 回忆 Tab 出现 1 条 |
| 4 | 首页点 **我** 签到 | 签到成功；若仅一人，streak 仍为 0（需双人同日） |
| 5 | 我们 → **签到记录** | 日历见「只有我」的格子 |

### 16.3 开发版一键演示数据（推荐自测分页/日历）

无需手动发 20 条动态：

1. 完成 **16.2 步骤 1～2**（已有空间即可）。  
2. **我们** Tab 底部 → **注入演示数据**（仅 `develop` / `trial` 显示）。  
3. 确认后写入：**22 条纯文字动态** + **近 14 天签到**（若已绑定另一半，部分日期为双人签到并更新 streak）。  
4. 去 **回忆** 上拉 → 应出现「加载更多」；**签到记录** 切换月份可见着色。  

### 16.4 双人绑定（测 streak / 她方动态）

- 创建者分享 **bind** 页卡片，对方通过带 `inviteToken` 的卡片加入；直接搜索打开不会自动加入。  
- 第二人账号签到后，首页 streak 才可能增加。  
- 单人开发可用演示数据模拟部分双人签到（已绑定 `memberB` 时）。

### 16.5 常见误解

| 现象 | 原因 |
|------|------|
| 回忆/首页图不显示 | 已修复：云 `fileID` 需换临时 HTTPS；重新编译 |
| 分页测不了 | 需 >20 条动态 → 用 **注入演示数据** 或自己多发 |
| 注入按钮看不见 | 正式版 `release` 不显示；请用开发者工具 **开发版** 编译 |
| `listMoments` 报错 | 云函数未重新部署，返回结构仍是旧版数组 |
