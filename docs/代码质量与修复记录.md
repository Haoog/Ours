# 代码质量与修复记录

本记录对应当前本地工作区，尚未代表云端已部署。以下是本次及上一轮排查中已落实的修改；同一问题可能影响多个入口。

## 账号与隐私

1. 阻止空间创建者通过自己的邀请占用第二个席位。
2. 阻止账号同时加入多个空间，并通过绑定文档约束并发请求。
3. 邀请已使用但响应丢失时，同一位成员可以安全重试。
4. 历史上自己占用两个席位的空间，可由创建者重新生成邀请时恢复。
5. 授权码和邀请先查文档 ID，再在事务内重新核验状态，避免事务使用条件查询。
6. 已进入删除流程的空间不能被管理台重新启用。
7. 分享卡片使用固定标题和封面，避免展示回忆正文、照片或页面截图。
8. 演示数据默认关闭，由云函数环境变量在独立测试环境显式开启。
9. 云文件访问和删除路径改为校验文件路径前缀，拒绝嵌套伪造路径和路径回退。

## 录音、上传与草稿

10. 从设置中开启麦克风权限后继续尝试录音。
11. 收到录音开始事件后才启动计时和显示录音状态。
12. 微信没有返回录音时长时，使用实际经过的时间判断。
13. 重录失败或拒绝权限时保留原语音。
14. 多次进入发布页时，录音管理器监听器不重复累加。
15. 达到媒体额度或页面尚未准备好时，录音按钮给出提示。
16. 语音流播放失败时，尝试下载到本地播放；最终失败时恢复按钮状态。
17. 离开详情页时取消尚未完成的语音加载，并清除失败的临时链接缓存。
18. 临时链接缓存不超过微信返回的有效期。
19. 上传改用可监听进度和取消的上传任务。
20. 取消发布后重置上传状态，避免后续上传一直失败。
21. 草稿中多个字段指向同一个文件时只复制一份。
22. 备份链接下载失败时尝试云存储下载；分享备份失败时提示重试。

## 日期、列表与互动

23. 服务端日期校验拒绝不存在的日期和未来的关系开始日。
24. 跨月、跨年和闰日的前一天计算不受服务器时区影响。
25. 客户端相伴天数避免夏令时切换造成少算一天。
26. 纪念日使用北京时间计算；2 月 29 日在非闰年按 2 月 28 日计算。
27. 已过去的一次性纪念日显示已过去天数，也不再作为下一个纪念日。
28. 旧记录缺日期时，那年今日和回顾统计会先补齐日期。
29. 媒体筛选按匹配结果分页，避免漏页或重复。
30. 评论、纪念日、签到和列表互动计数支持超过单次查询上限的数据。
31. 回忆详情的上一条和下一条只读取相邻记录，避免每次加载完整索引。
32. 切换筛选条件时，旧请求不会使“加载更多”一直转圈或弹出过时错误。
33. 切换回忆后，旧回忆的评论删除失败不会覆盖当前页面。
34. 点赞或发评论完成后及时标记列表刷新，避免切页时遗漏更新。
35. 评论和纪念日删除在响应丢失后可以安全重试。
36. 空回忆、空评论、空小纸条、空吐槽和空纪念日名称由服务端拒绝。
37. 地图跳过缺失或无效坐标，并兼容历史记录中的数字字符串。
38. 合辑按普通字符串统计地点，避免特殊名称影响对象属性。

## 文件与依赖

39. 云存储文件大小核验检查 HTTP 状态和分段响应，避免把一字节范围误算为完整文件大小。
40. 云文件删除缺少单个结果时保留重试任务；管理台删除空间也按同一原则处理。
41. 用量统计对缺失的历史媒体数量使用记录内容回退，失败的文件大小不会永久缓存为零。
42. 发布事务重新核验单条媒体额度，覆盖额度在上传期间被修改的情况。
43. 更新小程序和管理台云函数 SDK，消除当前审计中的 critical 项；管理台网页使用所需 SDK 模块。
44. 增加持续集成和回归测试，覆盖上述关键流程、边界及异步竞态。
45. 管理台云函数兼容 CloudBase Node SDK 单文档读取返回数组的格式，修复空间详情、授权和额度读取。
46. 管理台检查 SDK 返回的写入错误，暂停空间失败时不会继续执行删除。
47. 重建旧空间用量时，相同文件被多条记录引用会按记录分别计费，与发布及删除时的计算保持一致。
48. 大量回忆的评论和点赞统计分批查询，避免一次提交过多回忆 ID。
49. 管理台在排序索引不可用时先对全部候选记录排序再分页，避免每一页内部排序导致跨页顺序错误。

## 验证范围和待办

- 已运行类型检查、核心回归测试和管理台生产构建，并在浏览器确认管理台登录页面及 SDK 初始化；未连接真实管理账号验证权限和写入。
- 核心回归使用本地模拟数据库；它不能替代真实云开发事务、数据库索引、存储权限与真机验证。
- 微信开发者工具的命令行服务端口当前关闭，因此本轮无法通过 CLI 完成小程序实际编译。请在工具里编译，并用两台真机验证录音、播放、图片视频、邀请和备份。
- 当前 `ours` 生产依赖审计仍有 5 项 high 和 4 项 moderate，`admin-api` 仍有 4 项 high 和 1 项 moderate；均为依赖链告警，是否能由本项目实际触发尚未验证。升级 SDK 已消除两者原先的 critical 项，不建议未经云端验证强制降级 SDK。
- 大量媒体筛选目前兼容旧记录而需要扫描空间内匹配条件的记录；当单个空间增长很大时，可另做媒体类型索引和迁移。
- 数据库和云函数上线步骤以 [云开发部署说明](../cloud/README.md) 为准。
